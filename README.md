# 🔐 Password Strength Checker

A mini project built using **HTML, CSS, and Vanilla JavaScript** that provides real-time password validation and strength analysis.

As users type their password, the application validates multiple security criteria, updates a visual checklist, displays a dynamic strength meter, and allows toggling password visibility.

---

## 🚀 Features

- 👁️ Toggle password visibility (Show/Hide password)
- ✅ Real-time password validation
- 📊 Dynamic password strength meter
- 🎨 Color-coded strength indicator
- ✔️ Live checklist for password requirements
- 📱 Responsive and clean UI
- ⚡ Instant feedback without page reloads

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6)

---

## 📋 Password Validation Rules

The password is evaluated against the following criteria:

- Minimum 8 characters
- At least one lowercase letter
- At least one uppercase letter
- At least one number
- At least one special character

Based on the number of satisfied conditions, the password strength is categorized as:

- Too Weak
- Weak
- Medium
- Strong
- Very Strong
